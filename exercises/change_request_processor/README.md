# Change Request Processor

A Python learning project built to practice processing and validating structured change request data from a CSV file.

## What This Project Demonstrates

- Reading CSV files using Python
- Working with dictionaries
- Understanding and checking data structure/schema
- Detecting missing values
- Schema-aware type conversion
- Handling conversion errors
- Boolean conversion
- Range validation
- Membership validation
- Separating valid and invalid records
- Using `break` for fail-fast record validation
